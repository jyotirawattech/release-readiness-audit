# Changelog

All notable changes to this project are documented here.

## 0.1.0 — 2026-09-02

- Added the eight-question deterministic release-coordination audit.
- Added answer-derived and optional exact monthly person-hour estimates.
- Added partial exact-data support and an explicit weekly-to-monthly conversion.
- Separated operational pain from fixed-sprint implementation fit.
- Suppressed the paid route for healthy, low-volume, and out-of-scope workflows.
- Defined source integrations by API/access boundary and ranked advice by the strongest friction signal.
- Added aggregate-data boundaries, security guidance, examples, and forward-test cases.
